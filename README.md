# ♞ Chess Game

A complete chess game for the browser, written from scratch in **vanilla JavaScript** (no libraries), with two computer opponents: a classic **minimax search with alpha-beta pruning** and a **machine-learning evaluation trained by self-play**.

**▶ Play it online: [pedroolimendes.github.io/Chess-Game](https://pedroolimendes.github.io/Chess-Game/)**

> The interface is in Portuguese.

## Features

- **Full rules engine** — legal move generation with check, checkmate, stalemate, castling, en passant, promotion and insufficient material. Validated with [perft](https://www.chessprogramming.org/Perft_Results) against the standard reference counts (start position depth 4: 197,281 nodes; "Kiwipete" depth 3: 97,862 nodes).
- **Two AI opponents, three difficulty levels**
  - *Classic*: negamax with alpha-beta pruning, move ordering and quiescence search. Hand-written evaluation of material, center control, piece development, mobility and king safety.
  - *Neuron (ML)*: the same search, but positions are scored by a model whose weights were **learned**, not written by hand.
- **Evaluation bar** showing who is better (in pawns) or mate-in-N.
- **Move review** — step through the game with the toolbar or the arrow keys.
- Drag and drop or click to move, undo, resign, two-player mode.
- Wooden piece sounds **synthesized with the Web Audio API** (no audio files).
- Accessible markup (ARIA roles, keyboard support) and responsive layout.

## How the ML opponent learns

The learned evaluation is a single neuron (logistic regression):

```
P(white wins) = sigmoid(w · features(position))
```

The 13 features describe the position as "white minus black" (material per piece type, center control, development, castling, pawn shield, king exposure, mobility, king activity in the endgame).

[`train-ml.js`](train-ml.js) trains it with an AlphaZero-inspired loop:

1. Bots play thousands of games in parallel (one Node.js worker thread per CPU core), with randomized noise so the games vary.
2. Every position becomes a training example: features → final result (1, 0.5 or 0).
3. Weights are fitted with gradient descent (Adam optimizer), minimizing log loss, with a validation split.
4. The next generation is played by the neuron itself (**self-play**), and training reuses games from all generations (**replay buffer**).

The current weights in [`chess-ml-weights.js`](chess-ml-weights.js) came from 4 generations of 1,000 games. In the game, *"O que o neurônio aprendeu"* shows what each feature is worth in pawns.

## Run locally

No build step — just open `chessgame.html` in a browser.

To retrain the model (requires [Node.js](https://nodejs.org)):

```bash
node train-ml.js [games per generation] [generations]   # default: 1000 3
```

## Project structure

| File | Purpose |
| --- | --- |
| `chess-engine.js` | Board representation, move generation, rules, notation, perft |
| `chess-ai.js` | Minimax / alpha-beta search and hand-written evaluation |
| `chess-ml.js` | Feature extraction and learned evaluation |
| `chess-ml-weights.js` | Trained weights (generated by `train-ml.js`) |
| `train-ml.js` | Self-play training pipeline (Node.js, worker threads) |
| `chessgame.html` / `.css` / `.js` | User interface |

## Tech

JavaScript (ES6+), HTML5, CSS3, Web Audio API, Node.js `worker_threads`.
